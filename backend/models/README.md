# Model artifacts

These files are generated by `backend/scripts/train.py`. They are committed so Render can start
the API without running training. Do not edit them by hand.

| File | Contents |
| --- | --- |
| `scaler.joblib` | `StandardScaler` fitted on the 38 numeric KDD features |
| `pca.joblib` | `PCA(n_components=0.98)` fitted on the scaled numeric features |
| `gnb.npz` | Per-class mean/variance/classes for the notebook's Gaussian NB |
| `dt_tree.json` | The notebook's custom Gini decision tree as a portable JSON tree |
| `xgb_model.json` | `XGBClassifier` saved with `save_model` |
| `metadata.json` | Feature order, categorical vocabularies, label mapping and provenance |
| `metrics.json` | Verified artifact evaluation plus historical notebook reference figures |

Retrain with:

```powershell
python backend\scripts\train.py --data backend\data\kddcup.data_10_percent_corrected --output backend\models
```
